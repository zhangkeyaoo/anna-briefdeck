# 开发验证与发布记录

## 十小时安排

| 时间 | 里程碑 | 验收证据 |
| --- | --- | --- |
| 第 0–1 小时 | 规格、验收样例、Anna 开发者权限 | 固定输入、可创建应用的账号 |
| 第 1–4 小时 | 本地预览、编辑和 PPTX 导出 | 本地测试及 PowerPoint 打开证据 |
| 第 4–6 小时 | Anna 接入、打包与首轮 staging 验证 | 平台生成结果、额度记录 |
| 第 6–10 小时 | 提交审核、发布核对、准备 GitHub 交付 | 仓库 URL、App name、完整 slug、可访问状态 |

平台审核耗时由平台决定。提交审核后记录实际时间和状态，状态以控制台为准。

## 实施决定

- 浏览器界面直接通过 Anna Runtime 调用宿主模型。生成数据保留在当前界面，可随时导出。
- 固定内容结构和长度，预览与导出由同一份编辑数据驱动。
- 先用样例和模拟响应验证模型以外的所有步骤，再使用 staging 额度。

| 日期与版本 | 场景 | 调用前 | 调用后 | 消耗 | 结果 |
