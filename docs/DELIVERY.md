## 实施决定

- 浏览器界面直接通过 Anna Runtime 调用宿主模型。生成数据保留在当前界面，可随时导出。
- 固定内容结构和长度，预览与导出由同一份编辑数据驱动。
- 先用样例和模拟响应验证模型以外的所有步骤，再使用 staging 额度。

## 面试复盘

1. **需求取舍。** 将开放式「用 AI 做 PPT」收敛为项目进展汇报。设计六页固定结构，并用含真实风格指标、未验证风险和待决策事项的固定样例定义验收。
2. **技术取舍。** Anna 负责一次性生成结构化文本。代码校验结果并用固定版式渲染，PowerPoint 原生文本保留编辑能力。因为编辑和导出由本地处理，日常修改与调试不会多花模型额度。
3. **AI 协作。** 候选人与 Codex 确定首版目标、额度边界和交付标准，候选人开通账号并授权，Codex 协助把规格细化为实现、测试和交付记录。面试时用规格和验证表展示自己实际参与的判断、复核和实测。
4. **验收证据。** 先展示编辑后的文本进入真实 PowerPoint 文件，再展示 staging 的实际生成结果、额度记录和发布状态。将模拟测试与真实测试分开说明。
